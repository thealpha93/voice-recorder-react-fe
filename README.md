# Voice Recorder React

A voice recorder application built with React and Vite. It uses Socket.IO for real-time communication.

## Features

- Record audio
- Pause and resume recording
- Display recording duration
- Real-time communication with a backend server

## Deveopment
To install the dependencies, run:
```sh
npm install
```

To change the backend url, go to `src/configs/constants`

To start the development server, run:
```sh
npm run dev
```

## Build
To build the project, run:
```sh
npm run build
```
